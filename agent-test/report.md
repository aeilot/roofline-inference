# 最终默认配置的受控对照

每对在同一进程内对照，共享 BF16 权重和 GPU stream，相同 token 输入、greedy、生成长度、KVCache、chunk 大小和逐块分区；AB/BA 交错。默认只启用 decode 投影融合。

单位 ms；加速比是 baseline / agent，大于 1 表示 agent 更快。括号中是逐对加速比中位数的配对 bootstrap 95% 区间；不足四对时只列观测范围。重复数小、温度未锁定，区间仅反映这些观测样本的波动。
