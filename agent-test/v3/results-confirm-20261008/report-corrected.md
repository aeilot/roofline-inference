## 延续性检验（进程隔离是否足够）

同一 prompt 上测目标引擎，比较紧挨着的前一个进程是 E0 还是 E2：比值 = t(前为 E0) / t(前为 E2)。两个方向都测（目标 E2、目标 E0）。描述性判断：区间不含 1 → 探索性信号；区间落在 [0.98, 1.02] 内 → 尚未证明等价；否则无法排除。区间半宽只描述不确定性，不是最小可检出效应。
